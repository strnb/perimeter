# Contributing to Perimeter

Спасибо за интерес к проекту **Perimeter**!

Мы приветствуем любые предложения по улучшению платформы: исправления ошибок, новые возможности, улучшение документации и оптимизацию существующего кода.

---

# Как внести вклад

1. Сделайте Fork репозитория.
2. Создайте новую ветку.

```bash
git checkout -b feature/your-feature
```

3. Внесите изменения.

4. Убедитесь, что код соответствует архитектуре проекта.

5. Создайте Commit.

```bash
git commit -m "Add: short description"
```

6. Отправьте изменения.

```bash
git push origin feature/your-feature
```

7. Создайте Pull Request.

---

# Стиль кода

Мы придерживаемся следующих принципов:

- понятные имена переменных;
- модульная архитектура;
- отсутствие "магических" чисел;
- минимальное дублирование кода;
- обязательные комментарии для сложной логики;
- использование type hints;
- соблюдение PEP8.

---

# Структура проекта

Перед добавлением нового функционала убедитесь, что он соответствует существующей архитектуре.

Новые модули рекомендуется размещать внутри каталога:

```
core/modules/
```

Новый функционал не должен нарушать существующий Pipeline аудита.

---

# Сообщения Commit

Рекомендуемый формат:

```
Add: DLP detection

Fix: PDF generation

Refactor: Scanner module

Docs: Update README

UI: Improve dashboard
```

---

# Сообщения об ошибках

Если вы нашли ошибку, пожалуйста, приложите:

- версию проекта;
- операционную систему;
- шаги воспроизведения;
- ожидаемый результат;
- фактический результат;
- лог ошибки (если имеется).
