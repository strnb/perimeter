# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- `tests/test_docs.py` — проверка ссылок, якорей, команд и флагов в документации.
- `docs/` — руководство по сценариям, справочник, архитектура.
- `CONTRIBUTING.md`, `CHANGELOG.md`.
- CI: тесты и проверка документации на Ubuntu и Windows (Python 3.10, 3.12).
- `perimeter pipeline --json` пишет структурированный JSON (dataclass → объект).
- Тесты на все исправления ниже.

### Исправлено

- **DLP:** пароли из заглавных букв и цифр (`DB_PASSWORD=PRODSECRET2024`)
  больше не считаются заглушками и находятся.
- **Vault:** потеря `.salt` даёт понятную ошибку и не создаёт новый ключ;
  порядок первого запуска исправлен (соль создаётся до `.master`).
- **Отчёты:** имена файлов содержат микросекунды — два отчёта подряд больше не
  затирают друг друга.
- **OSINT:** CNAME запрашивается и при наличии A — проверка subdomain takeover
  работает для висячих CNAME, которые резолвятся через CDN.
- **OSINT:** crt.sh и hackertarget запрашиваются с проверкой TLS-сертификата;
  `verify=False` остался только для проб целей.
- **OSINT:** `--active` делает не более 200 HTTP-проб (было — все имена).
- **CLI:** `init_db()` вызывается в `main()`, а не при импорте — `-h` и
  `vault list` работают на read-only дереве.
- **История:** HIGH больше не считается CRITICAL (колонка `high_count`,
  миграция, PDF и `history`).
- **Сканер:** ответ SMB Negotiate больше не помечается `VULNERABLE`; убрано
  правило SSH по одному факту открытого порта; IRC понижен до LOW; FTP/Telnet
  требуют реального баннера.
- **PDF:** добавлены счётчик находок OSINT и срок истечения домена.
- **История:** кэшированный OSINT-скан не создаёт дублирующую запись.
- **`history`:** человекочитаемый вывод DLP/NETWORK/OSINT вместо `col=value`.
- **`web --help`:** описание соответствует реальным проверкам (только DVWA).

### Изменено

- **`pipeline`:** скан портов выключен по умолчанию (`--scan`), потому что IP
  за CDN принадлежат провайдеру. Печатается сводка, полный отчёт — `--json`.
- **`api/network.py`:** убрана избыточная проверка статуса после фильтрации.

### Удалено

- Мёртвый профиль `GENERIC` в веб-сканере, неиспользуемый
  `api.paths.DEFAULT_WORDLIST`, дублирующая проверка статуса, безусловное
  `vulnerable=True` у distccd.

## [1.0.0] — 2026-11-27

Первый публичный релиз: DLP с историей git, обновлённый OSINT, отчёты,
vault, MIT.

### Добавлено

- **DLP:** детекторы паролей, токенов (AWS, GitHub, GitLab, OpenAI, Stripe,
  Slack, Google, SendGrid, npm, DigitalOcean, Telegram, JWT), приватных ключей
  (RSA, DSA, EC, OpenSSH, PKCS#8, encrypted, PGP, PuTTY), строк подключения с
  паролем, файлов хешей паролей, `.netrc`, дампов секретов, SQLi / command
  injection / слабых сессий.
- **DLP:** скан истории git (`--git`, `--git-depth`) с коммитом, автором, датой
  и числом коммитов; без дублей с рабочим деревом.
- **DLP:** маскировка секретов по умолчанию (`--show-secrets` для полных
  значений); в базу пишутся только счётчики.
- **DLP:** YARA-правила для файловых условий (AWS-пара, shadow/htpasswd,
  `.netrc`, дамп секретов); компиляция один раз за процесс.
- **DLP:** кодировки UTF-16/UTF-8/cp1251/latin-1, BOM, отсечение бинарников,
  лимит 1 МБ, отсечение каталогов сборок и lock-файлов.
- **OSINT:** WHOIS с датами и сроком; 9 типов DNS; crt.sh; hackertarget;
  wordlist 2 274 имени и автопоиск SecLists; кэш 24 ч; diff поддоменов с
  прошлым сканом.
- **OSINT:** проверки SPF, DMARC, DKIM, DNSSEC, CAA; AXFR, HTTP/TLS-пробы,
  панели управления, кандидаты на subdomain takeover (`--active`).
- **Сканер портов:** 33 порта по умолчанию, баннеры, сигнатуры по баннеру,
  порту и активному подтверждению; лимит 65 536 проверок; активные пробы
  MySQL/PostgreSQL/MongoDB (`.[db-checks]`).
- **Vault:** PBKDF2-HMAC-SHA256 (480 000 итераций) + Fernet, солёный хеш
  мастер-пароля, атомарная запись, права `0600/0700`, миграция старого формата.
- **Отчёты:** JSON/TXT по находкам, полный JSON OSINT, PDF по истории с
  экранированием и кириллическим шрифтом.
- **CLI:** справка по каждой команде, подсказка при опечатке, коды возврата,
  автодополнение bash/zsh/PowerShell 7+.
- База знаний: 50 записей с описанием, риском и рекомендацией.
- Тесты: `tests/test_cli.py`, `tests/test_dlp.py`, `tests/test_osint.py`.
- `LICENSE` (MIT), метаданные пакета, публикация данных в wheel.

### Изменено

- Секреты в отчётах и консоли маскируются по умолчанию.
- Сигнатуры не ставят CVE по имени сервиса: только баннер или активное
  подтверждение.

### Исправлено

- PDF падал на `<`, `>` и `&` из баннеров и путей.
- DLP не видел `id_rsa`, `.pem`, `.key` и пароли вне `.env`.
- `perimeter scan 10.0.0.0/8` съедал память до первого пакета.
- Vault с несолёным SHA-256 мигрирует при первом входе.
- Кириллица в PDF (шрифт DejaVuSans).

## [0.9.0] — 2026-11-24

### Добавлено

- Единая справка `perimeter -h` и `perimeter <команда> -h`.
- Подсказка ближайшей команды при опечатке.
- Автодополнение для bash, zsh, PowerShell 7+.
- Docstrings для модулей и обработчиков CLI.

### Изменено

- Убраны лишние файлы и дублирующиеся проверки.
