# Changelog

Все значимые изменения проекта **Perimeter** будут документироваться в этом файле.

Формат основан на стандарте **Keep a Changelog** и принципах **Semantic Versioning**.

---

## [1.0.0] - 2026-07-XX

### 🎉 Первый публичный релиз

Первая версия Perimeter, представленная в рамках **Kodik Hackathon 2026**.

---

### ✨ Добавлено

#### Инфраструктурный аудит

- Реализован TCP Port Scanner.
- Определение открытых портов.
- Определение доступности сервисов.
- Подготовка данных для дальнейшего анализа.

---

#### Web Scanner

- Анализ HTTP-заголовков.
- Проверка HTTPS/TLS.
- Анализ конфигурации веб-приложения.
- Определение используемых технологий.
- Формирование рекомендаций.

---

#### DLP

- Поиск чувствительных данных внутри проектов.
- Обнаружение API-ключей.
- Поиск JWT.
- Поиск GitHub Token.
- Поиск AWS Credentials.
- Поиск SSH-ключей.
- Поддержка пользовательских правил YARA.

---

#### Vault

- Добавлено защищённое хранилище найденных данных.
- Подготовлена архитектура для безопасной работы с чувствительной информацией.

---

#### Knowledge Base

- Добавлена база знаний.
- Описание найденных проблем.
- Рекомендации по устранению.
- Оценка потенциальных рисков.

---

#### Report Generator

- Генерация PDF-отчётов.
- Экспорт результатов в JSON.
- Структурированное отображение результатов проверки.

---

#### Пользовательский интерфейс

- Реализована базовая навигация.
- Добавлены страницы модулей.
- Интеграция модулей в единое приложение.

---

#### Архитектура

- Реализована модульная архитектура проекта.
- Добавлен единый Pipeline аудита.
- Унифицирован интерфейс взаимодействия между модулями.

---

### 🔒 Безопасность

- Добавлена поддержка локального анализа проектов.
- Проверка чувствительных данных.
- Анализ конфигураций.
- Подготовка платформы к дальнейшему развитию механизмов аудита безопасности.
