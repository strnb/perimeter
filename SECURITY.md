# Security Policy

## Поддерживаемые версии

На данный момент поддерживается последняя версия проекта.

| Version | Supported |
|----------|-----------|
| 1.x | ✅ |
| <1.0 | ❌ |

---

# Сообщение об уязвимостях

Если вы обнаружили проблему безопасности, пожалуйста, **не публикуйте её публично до её исправления**.

Вместо этого создайте приватное обращение через GitHub Issues или свяжитесь с командой проекта.

При сообщении желательно указать:

- описание проблемы;
- шаги воспроизведения;
- потенциальные последствия;
- версию проекта;
- операционную систему;
- дополнительные материалы (при необходимости).

---

# Обработка данных

Perimeter разработан как локальное приложение.

Во время работы:

- пользовательские данные не отправляются на внешние серверы;
- анализ выполняется локально;
- результаты остаются на устройстве пользователя.

---

# Ответственное раскрытие информации

Мы ценим ответственное сообщение об уязвимостях.

После подтверждения проблемы команда:

- воспроизведёт её;
- подготовит исправление;
- уведомит автора сообщения;
- включит исправление в следующий релиз.

Спасибо за помощь в повышении безопасности проекта.
