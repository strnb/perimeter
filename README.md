# О проекте

Современная проверка безопасности редко ограничивается одним инструментом. Для полноценного аудита разработчикам, DevOps-инженерам и специалистам по информационной безопасности приходится использовать разные приложения: сетевые сканеры, DLP-системы, анализаторы веб-приложений, генераторы отчётов и базы знаний.

Такой подход требует постоянного переключения между инструментами, усложняет анализ результатов и увеличивает вероятность пропустить важную проблему.

**Perimeter** — это локальная платформа, объединяющая наиболее востребованные сценарии проверки безопасности проектов и инфраструктуры в одном приложении.

Вместо запуска нескольких отдельных утилит пользователь получает единое рабочее пространство, которое автоматически выполняет необходимые проверки, объединяет результаты и предоставляет понятный отчёт с рекомендациями.

Главная цель проекта — **не заменить специализированные инструменты**, а предоставить единый центр проверки безопасности, позволяющий быстро выполнять большинство повседневных задач без необходимости собирать собственный набор утилит.

---

## Почему не использовать несколько отдельных инструментов?

Perimeter не пытается заменить специализированные решения, такие как Nmap, TruffleHog, Gitleaks или OWASP ZAP.

Каждый из этих инструментов отлично решает свою задачу.

Однако в типичном процессе проверки разработчику приходится:

- самостоятельно выбирать нужные утилиты;
- запускать их по отдельности;
- анализировать результаты в разных форматах;
- сопоставлять найденные проблемы;
- вручную формировать итоговый отчёт.

Perimeter автоматизирует этот процесс.

Пользователь запускает одну проверку и получает единый результат, объединяющий данные из различных этапов анализа.

Основная ценность платформы заключается не в замене существующих инструментов, а в сокращении времени, необходимого для проведения комплексной проверки проекта.


#  Для кого создан Perimeter?

Perimeter ориентирован на разработчиков и команды, которым необходимо регулярно выполнять базовую проверку безопасности проектов и инфраструктуры без использования большого количества разрозненных инструментов.

Платформа подходит как для повседневной работы, так и для образовательных и исследовательских задач.

---

##  Разработчики

Перед публикацией проекта важно убедиться, что в репозиторий случайно не попали чувствительные данные или потенциально опасные конфигурации.

Perimeter помогает:

- обнаружить API-ключи, токены и пароли;
- найти приватные ключи и сертификаты;
- проверить конфигурационные файлы;
- выполнить базовый аудит проекта перед релизом.

---

##  Стартапы и небольшие команды

Небольшие команды часто не имеют отдельного отдела информационной безопасности и вынуждены самостоятельно контролировать качество своих проектов.

Perimeter позволяет выполнять регулярные проверки без сложной настройки специализированных решений и объединяет результаты анализа в одном интерфейсе.

---

##  DevOps и инфраструктурные инженеры

При работе с инфраструктурой важно быстро получить представление о состоянии сервисов и доступных сетевых ресурсов.

Perimeter предоставляет инструменты для:

- проверки открытых портов;
- анализа веб-приложений;
- первичного аудита инфраструктуры;
- формирования отчётов по результатам проверки.

---

##  Образовательные учреждения и студенты

Perimeter может использоваться как учебная платформа для знакомства с практическими аспектами безопасной разработки и основами аудита безопасности.

Объединение нескольких сценариев проверки в одном приложении делает процесс обучения более наглядным и удобным.

Perimeter не заменяет специализированные инструменты профессионального уровня, но позволяет быстро выполнить первичный аудит проекта или инфраструктуры и получить структурированные результаты для дальнейшего анализа.

Платформа особенно полезна на этапе предварительной оценки, когда требуется оперативно выявить наиболее распространённые проблемы безопасности.

## Когда Perimeter наиболее полезен?

Наиболее типичные сценарии использования:

- проверка проекта перед публикацией или передачей заказчику;
- аудит внутреннего корпоративного проекта;
- анализ тестовой инфраструктуры;
- проведение учебных лабораторных работ;
- подготовка отчётов по результатам проверки;
- выполнение первичного аудита безопасности без необходимости запускать несколько отдельных инструментов.

#  Наша цель

Мы не ставили перед собой задачу создать ещё один специализированный сканер безопасности.

Цель Perimeter — объединить наиболее востребованные сценарии проверки безопасности проектов и инфраструктуры в одном приложении.

Мы стремимся сократить количество рутинных действий, которые ежедневно выполняют разработчики и специалисты по информационной безопасности, предоставив единое рабочее пространство для аудита, анализа и формирования отчётов.

Perimeter помогает сосредоточиться не на запуске множества отдельных инструментов, а на анализе результатов и устранении найденных проблем.

# Почему Perimeter?

Сегодня инженеру безопасности или разработчику часто приходится использовать сразу несколько различных инструментов:

- поиск секретов в проекте;
- анализ веб-приложения;
- аудит инфраструктуры;
- проверка конфигурации;
- изучение найденных проблем;
- формирование отчётов.

Каждый из этих этапов обычно выполняется независимо, что увеличивает время проверки и усложняет работу.

**Perimeter объединяет эти процессы в одном приложении**, предоставляя единый интерфейс для проведения аудита и анализа результатов.

Такой подход позволяет:

- сократить время проведения проверки;
- уменьшить количество используемых инструментов;
- централизовать результаты анализа;
- быстрее находить потенциальные проблемы безопасности;
- получать рекомендации по их устранению.

# Основные возможности

##  Аудит инфраструктуры

Проверка сетевой инфраструктуры и внешних ресурсов.

Возможности:

- сканирование TCP-портов;
- определение открытых сервисов;
- анализ сетевой инфраструктуры;
- OSINT-анализ;
- первичная оценка состояния ресурсов.

---

##  Анализ веб-приложений

Проверка опубликованных веб-ресурсов.

Включает:

- анализ HTTP-заголовков;
- проверку HTTPS/TLS;
- определение используемых технологий;
- аудит конфигурации веб-приложения;
- оценку уровня защищённости.

---

##  Проверка локальных проектов

Perimeter позволяет проверить проект ещё до публикации или передачи заказчику.

Во время анализа выполняется поиск:

- секретов;
- API-ключей;
- токенов доступа;
- приватных ключей;
- конфигурационных ошибок;
- потенциально опасных файлов.

---

##  DLP-модуль

Встроенный модуль обнаружения чувствительных данных способен автоматически находить:

- пароли;
- JWT-токены;
- GitHub Token;
- GitLab Token;
- AWS Credentials;
- SSH-ключи;
- сертификаты;
- приватные ключи;
- другие чувствительные данные с использованием регулярных выражений и правил YARA.

---

##  База знаний

Каждая найденная проблема сопровождается дополнительной информацией:

- описание;
- уровень риска;
- возможные последствия;
- рекомендации по устранению.

Это позволяет не только обнаружить проблему, но и понять причины её возникновения и способы исправления.

---

##  Генерация отчётов

По результатам проверки Perimeter формирует структурированные отчёты, которые могут использоваться для анализа, документирования результатов и последующей работы над найденными проблемами.

На данный момент поддерживаются:

- PDF;
- JSON.

В дальнейшем список поддерживаемых форматов будет расширяться.

# 🏗 Архитектура платформы

Perimeter построен по модульному принципу, что позволяет независимо развивать отдельные компоненты системы и постепенно расширять возможности платформы.

```
                         Perimeter
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
  Аудит проекта        Аудит инфраструктуры    Анализ веб-приложений
        │                     │                     │
        ├──────────────┬──────┴──────────────┐
        │              │                     │
       DLP         Port Scanner        Web Scanner
        │              │                     │
        └──────────────┼─────────────────────┘
                       │
               Knowledge Base
                       │
                 Report Generator
                       │
                 PDF / JSON Report
```

Каждый модуль отвечает за собственную область анализа и может использоваться независимо, при этом результаты объединяются в единый отчёт.

Такой подход позволяет легко расширять платформу и добавлять новые возможности без изменения существующей архитектуры.

- подготовка данных для дальнейшего аудита.

##  Web Scanner

Модуль анализа опубликованных веб-приложений.

Поддерживает:

- анализ HTTP-заголовков;
- проверку HTTPS;
- определение технологий;
- оценку конфигурации безопасности;
- поиск распространённых проблем.

---

##  DLP Engine

Автоматически обнаруживает чувствительные данные внутри проекта.

Поиск включает:

- API Keys;
- JWT;
- GitHub Tokens;
- AWS Credentials;
- SSH Keys;
- Private Keys;
- сертификаты;
- пользовательские правила YARA.

---

## Vault

Безопасное хранение найденной информации.

Позволяет централизованно работать с чувствительными данными без их случайного раскрытия.

---

##  Knowledge Base

Каждая найденная проблема сопровождается дополнительной информацией.

Пользователь получает:

- описание проблемы;
- возможные последствия;
- рекомендации по исправлению;
- справочную информацию.

---

##  Report Generator

После завершения проверки Perimeter автоматически формирует отчёт.

Поддерживаются:

- PDF;
- JSON.

Отчёты содержат найденные проблемы, их описание и рекомендации по устранению.

#  Формирование отчётов

После завершения проверки пользователь получает структурированный отчёт со всеми найденными проблемами.

Каждая находка содержит:

- уровень риска;
- краткое описание;
- рекомендации;
- дополнительные сведения из базы знаний.

Поддерживаемые форматы:

- PDF — для передачи результатов и документирования;
- JSON — для интеграции с другими системами и автоматизации обработки.

В дальнейшем планируется поддержка HTML-отчётов и расширенных форматов экспорта.

Основная цель Dev Productivity — уменьшить количество рутинных действий разработчика и сделать процесс создания программного обеспечения более удобным и безопасным.

Именно поэтому проект соответствует направлению **Dev Productivity** — он помогает разработчикам и инженерам быстрее выполнять регулярные проверки безопасности, не переключаясь между большим количеством различных инструментов.
